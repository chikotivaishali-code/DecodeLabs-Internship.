# 🧠 Project 1: Rule-Based AI Chatbot

A simple chatbot built using Python and rule-based logic that responds to predefined user inputs using conditional statements and dictionary mapping.

## 🔹 Features
- Greeting and exit handling
- Continuous conversation loop
- User input sanitization
- Dictionary-based response mapping
- Beginner-friendly AI chatbot logic

## 🔹 Technologies Used
- Python
- Conditional Statements
- Dictionaries
- Loops

- Confusion matrix visualization
